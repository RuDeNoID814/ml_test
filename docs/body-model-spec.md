# Body Model — спецификация

## Референсы
Референсные изображения — в `docs/references/body-model/`.

Целевой стиль: гибрид "матово-белый манекен" (референс infobae, image 1) + "стилизованная 3D-фигура среднего уровня детализации" (референс low-poly с цветными частями, image 2). Уровень детализации ~ второй референс, материал ~ первый.

Третий референс (полигональный wireframe) — только как схема пропорций мужской фигуры.

## Рендер-стек
- Three.js + React Three Fiber (@react-three/fiber)
- @react-three/drei для хелперов (useGLTF, OrbitControls на будущее)
- Формат файла: GLB
- Морфы через `morphTargetInfluences`

## Меш
- Пол: только М в v1
- Полигональность: 2000–3000 треугольников
- Размер файла: <500 КБ
- Базовая T-поза
- Топология оптимизирована под 6 морфов ниже

## Морфы (6 штук)

| Морф | Диапазон 0..1 | Что меняет |
|---|---|---|
| `body_fat_torso` | 0 = сухо, 1 = ожирение | Живот, бока, полнота торса |
| `muscle_upper` | 0 = не тренирован, 1 = развит | Плечи, грудь, руки (bicep + предплечье как единое целое) |
| `muscle_lower` | 0 = не тренирован, 1 = развит | Бёдра, ягодицы, икры |
| `shoulder_width` | 0 = узкие, 1 = широкие | Ширина плечевого пояса (независимо от мышц) |
| `hip_width` | 0 = узкие, 1 = широкие | Ширина таза |
| `posture` | 0 = ровная, 1 = сутулая | Наклон верхней части позвоночника |

Рост — не морф, а `mesh.scale.y` (базовый рост меша принимается за 175 см, реальный рост / 175 = множитель).

## Маппинг: профиль → морфы

Реализация в `/lib/body/mapProfileToMorphs.ts`.

- `body_fat_torso` ← % жира с биоимпеданса (нормированный 5–40 → 0..1). Без биоимпеданса → формула Deurenberg (BMI + возраст + пол).
- `muscle_upper` / `muscle_lower` ← % мышц с биоимпеданса, распределённый 50/50. Без биоимпеданса → 0.4 по умолчанию.
- `shoulder_width` ← обхват груди в см, нормированный по типовому диапазону М. Без данных → 0.5.
- `hip_width` ← обхват таза, нормированный. Без данных → 0.5.
- `posture` ← поле профиля напрямую.

## Fallback при нехватке данных
Показывать модель с дефолтными значениями морфов + плашку "уточни параметры для точности". Не блокировать использование приложения.

## Материал
PBR, matte white mannequin:
- Base color: `#EAEAEA` (слегка серый белый)
- Roughness: 0.4
- Metalness: 0.0
- Освещение: одно направленное сверху-спереди (интенсивность 1.0) + мягкий ambient (0.3)

## Workflow создания меша

1. MakeHuman — сгенерировать базовый меш М-фигуры среднего телосложения
2. Экспорт из MakeHuman в OBJ или FBX
3. Blender — импорт, ретопология до 2–3k tris (Decimate + ручной клинап)
4. Blender — создание 6 Shape Keys, по одному на каждый морф из таблицы выше
5. Blender — экспорт в GLB с включённой опцией **Shape Keys** в панели glTF Export
6. Проверка: `mesh.morphTargetDictionary` в Three.js должен содержать 6 ключей с теми же именами

## Оптимизация
- Файл GLB закомпилировать через glTF-Transform или gltfpack (draco compression) при финальном экспорте
- Целевой размер после компрессии: <300 КБ
- Draw calls: 1 (один меш, один материал)
