# Life Game — Vision

## Что это

Веб-приложение "играй в свою жизнь". Персональный дашборд тела и образа жизни: пользователь задаёт свои параметры → приложение визуализирует его в виде интерактивной 3D-модели → показывает связи между параметрами → выдаёт нейтральные data-driven рекомендации.

Аналогия: RPG-персонаж, но это ты сам. Каждый параметр реальной жизни (вес, сон, еда, обхваты, биоимпеданс) влияет на модель и подсказки.

## Ключевые принципы

1. **Event-driven, не daily-check-in.** Пользователь открывает приложение, когда что-то изменилось. Никаких принудительных чек-инов, квестов, XP, стриков.
2. **Каждый параметр влияет на что-то.** Приложение обнажает связи, которые в жизни неочевидны (сон↔вес, кортизол↔жир, обхваты↔размер одежды).
3. **Нейтральный тон.** Ни мотивации, ни оценки. Формат подсказки: "лечь сегодня в 23:30" (data-driven), не "молодец, вперёд".
4. **3D-модель тела в центре продукта.** Не аватар с лицом. Не иконка. Полноценная фигура, меняющаяся от реальных данных.
5. **Local-first.** Все данные на устройстве. Синхронизация — v2.

## Аудитория MVP

Один пользователь — автор проекта. Сначала работающий продукт для себя, потом — публика.

## Что это НЕ

- Не мотивационное приложение
- Не соцсеть, никакой публикации данных
- Не тренировочный планировщик
- Не диетолог с готовыми планами
- Не игра с квестами, XP, уровнями
