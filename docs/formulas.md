# Формулы расчётов

Справочник формул, которые используются в приложении. 

## BMR — базальный метаболизм (ккал/сутки)

**Формула Миффлина-Сан Жеора (Mifflin-St Jeor, 1990)** — современный стандарт, точнее старой формулы Харриса-Бенедикта.

- **Мужчины:** `BMR = 10 · вес(кг) + 6.25 · рост(см) − 5 · возраст(лет) + 5`
- **Женщины:** `BMR = 10 · вес(кг) + 6.25 · рост(см) − 5 · возраст(лет) − 161`

BMR — это сколько калорий организм тратит в покое (базовый обмен), без учёта физической активности.

## Дневная норма калорий (TDEE)

`TDEE = BMR · коэффициент активности`

| Уровень активности | Коэффициент | Кому |
|---|---|---|
| Сидячий | 1.2 | Офисная работа, минимум движения |
| Лёгкая активность | 1.375 | 1–3 тренировки в неделю |
| Средняя активность | 1.55 | 3–5 тренировок в неделю |
| Высокая активность | 1.725 | 6–7 тренировок в неделю |
| Очень высокая | 1.9 | Физическая работа + спорт |

TDEE (Total Daily Energy Expenditure) — сколько калорий тратится за сутки с учётом активности. Это и есть суточная норма для поддержания веса.
