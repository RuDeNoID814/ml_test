# MVP scope — v1

## Входит в v1

### Профиль пользователя
- Никнейм
- Пол (только М)
- Дата рождения
- Рост
- Стартовый вес
- Опциональное поле осанки (0 = ровная, 1 = сутулая)

### Логи параметров
- **Вес** — с контекстом (натощак / после еды / вечером / другое), обязательный timestamp
- **Сон** — два отдельных события: "начал засыпать", "проснулся"
- **Еда** — ручной ввод, без штрихкодов. Продукты из локального справочника, лог порциями (граммы)
- **Блюда (конструктор)** — набор ингредиентов + общий вес → автоматический расчёт кКал/БЖУ на 100 г готового блюда

### 3D-модель тела
- Один меш (М), 6 морфов, PBR-материал (белый матовый манекен)
- Обновляется live от параметров профиля
- Фронтальный вид
- Спецификация в `body-model-spec.md`

### Data-driven подсказки
- Простой движок правил (5–10 правил на v1, конкретный список фиксируется в отдельном документе позже)
- Формат: "если [условие] → показать [фразу]"
- Правила в конфиг-файле, не в коде

### Инфраструктура
- Local-first (Dexie / IndexedDB)
- Экспорт/импорт всей БД в JSON — для бэкапа и ручного переноса
- Работает офлайн

## НЕ входит в v1 (отложено в v2+)

- Биоимпеданс как отдельный ввод (в v1 идёт заглушкой в маппинге морфов)
- Обхваты тела (шея, бицепс, талия и т.д.) как ввод
- Фотофиксация с рамкой "спереди/сбоку/сзади"
- Сканирование штрихкодов + интеграция с Open Food Facts
- Женская модель
- Полный 360° поворот модели
- Сравнение "до/после" со слайдером времени
- Синхронизация между устройствами
- Auth и облачная БД (Supabase)
- Мобильная сборка (Capacitor)
- Публичный лендинг

## Критерий готовности v1
Автор проекта использует приложение каждый день неделю подряд без багов, блокирующих логирование или отображение модели.
