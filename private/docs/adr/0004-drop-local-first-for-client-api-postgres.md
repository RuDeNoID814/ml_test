# Отказ от local-first (Dexie как источник истины) в пользу client → API → Postgres

Текущая архитектура хранит все пользовательские данные локально в браузере через Dexie/IndexedDB, без сервера. Это конфликтует с планами: работа с нескольких устройств (ноутбук + ПК с синхронизацией папок), будущая команда, VDS-хостинг с реальными пользователями.

Решено: когда появится бэкенд (см. [0003](./0003-backend-stack-postgres-prisma-authjs-minio.md)), IndexedDB перестаёт быть источником истины — либо убирается совсем, либо остаётся lightweight-кэшем поверх API. Схема данных: клиент → API (Next.js Route Handlers) → Postgres.

Полноценный local-first с sync-движком (аналоги ElectricSQL/PowerSync/Replicache) сознательно не делаем — сложность несоразмерна команде из 2–3 человек и текущему масштабу проекта.
