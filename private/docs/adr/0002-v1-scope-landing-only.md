# Scope v1.0.0 — только главная страница, остальное за заглушками в pre-version

Текущий код включает 5 маршрутов (`/`, `/onboarding`, `/profile`, `/weight`, `/measurements`), все технически рабочие и без TODO в самих страницах. Для первого публичного релиза (v1.0.0) в `main` остаётся только главная страница — которая к тому же переделывается заново (текущий вид оценён как «выглядит как ИИ»). Остальные страницы переносятся в ветку `pre-version` для дальнейшей доработки.

На месте перенесённых разделов в v1.0.0: где-то видимая заглушка «в разработке», где-то раздел вообще не показывается в навигации — решается по каждой странице отдельно, не единым правилом.

Ветвление: `main` — ветка-релиз/витрина для пользователей, `pre-version` — интеграционная ветка разработки, фиче-ветки создаются от неё и мержатся обратно.

**Considered options**: оставить все 5 страниц как есть, просто добавить дисклеймер «бета» — отклонено, часть разделов пользователь прямо назвал «странными» и не готовыми к показу.
